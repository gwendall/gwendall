# Hi, I'm Gwendall 👋

I build weird things across games, robots and agents.

Right now that means classic games, played in new ways: in mixed reality, alongside
AI agents, and by a fruit fly brain.

## Now

- [**Multitap**](https://multitap.gg) - the games you know, like you've never played them. Here's [what it looks like](https://x.com/gwendall/status/2105796481366266100). The early access list is open.
- [**Kami Robotics**](https://kamirobotics.com) - one mind, any body: the layer that makes an agent present and alive, on a screen, a robot or an object.
- [**Flycade**](https://flycade.com) - a fruit fly brain learns to play Street Fighter II, on an arcade cabinet, live in your browser.
- [**Le Cercle**](https://cercle.gg) - play a game, plug in an agent: sixteen browser games where people and agents play the same matches through one API.
- [**thenwhat.tv**](https://thenwhat.tv) - interactive generative TV: the room pitches what happens next, the top idea becomes the next scene.

## Tools for agents

- [**Tasq**](https://tasq.run) - local-first task tracking that humans and AI agents share without stepping on each other. [Source](https://github.com/gwendall/tasq)
- [**Domani**](https://domani.run) - domains, DNS and email, built for humans and AI agents. [Source](https://github.com/gwendall/domani)
- [**skills**](https://github.com/gwendall/skills) - my agent skills for Claude Code and Codex.

## Open source

- [**PXFACE**](https://github.com/gwendall/pxface) - a 3x5 pixel type system you can hack pixel by pixel, with a studio and an installable font.
- [**SuperClaude**](https://github.com/gwendall/superclaude) - AI-assisted GitHub workflows for commits, changelogs and code reviews.
- [**way.js**](https://github.com/gwendall/way.js) - simple, lightweight, persistent two-way databinding. Old, still loved.
- Patches sent upstream to libretro: [RetroArch](https://github.com/libretro/RetroArch), [Nestopia](https://github.com/libretro/nestopia).

Everything else, past work included, lives on [gwendall.com](https://gwendall.com).
